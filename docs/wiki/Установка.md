# Установка

Нужен Python **3.11 или новее** с Tkinter. CI проверяет Windows и Linux с Python 3.11–3.13. Устанавливайте зависимости в отдельное виртуальное окружение.

```console
git clone https://github.com/gorniy11/Inventory-Scanner.git
cd Inventory-Scanner
python -m venv .venv
```

В Windows PowerShell команды можно запускать без изменения политики выполнения:

```powershell
.\.venv\Scripts\python.exe -m pip install -e ".[dev]"
.\.venv\Scripts\python.exe -m inventory_scanner
```

В Linux/macOS используйте `.venv/bin/python`. Если Tkinter отсутствует, установите пакет Tk для используемой сборки Python через менеджер пакетов ОС.

## Режимы

```console
python -m inventory_scanner
python -m inventory_scanner --live
python -m inventory_scanner --live --data-dir ./local-data
```

Первая команда показывает сохранённый пример. `--live` разрешает разовую сетевую сессию. Без `--data-dir` результаты находятся во временном каталоге; экспортируйте их до закрытия. При заданном каталоге пример и реальные результаты хранятся в разных базах.

Пароль, Steam cookies и API key не нужны. Можно читать только доступные публичные инвентари.
