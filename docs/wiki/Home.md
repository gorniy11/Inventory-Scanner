# Inventory Scanner

Приложение на Python для разового просмотра публичных Steam-инвентарей. Поддерживает **CS2, Dota 2, Rust и TF2**, русский интерфейс, фильтры и экспорт результатов.

## Быстрый старт

```console
python -m pip install -e ".[dev]"
python -m inventory_scanner
```

По умолчанию открывается сохранённая выборка реальных публичных предметов. Для её просмотра сеть и вход в Steam не нужны. Это исторический пример, а не текущий инвентарь владельца.

Ознакомительная сессия ограничена тремя профилями, одним проходом по каждому инвентарю и 50 HTTP-запросами. Автоматических обменов и постоянного мониторинга нет.
