# Тестирование

```console
python -m pip install -e ".[dev]"
ruff check src tests tools
python -m unittest discover -s tests -v
python tools/check_gui.py
python -m inventory_scanner --version
```

GUI-проверка требует доступного рабочего стола. Сетевые обращения в ней запрещены; используется сохранённый реальный пример.

## Подтверждено 5 ноября 2026

- 62 автоматических теста: успешно.
- Настоящее окно: фильтры, неизвестные значения, вкладки при 1380×900 и 1080×740; внешних запросов — 0.
- Основные сетевые тесты используют подготовленные ответы: четыре игры, пагинация, дубли, неполные страницы, ошибки и лимиты.
- Существующий workflow проверяет Windows/Linux и Python 3.11–3.13. Текущее состояние конкретного коммита смотрите в [Actions](https://github.com/gorniy11/Inventory-Scanner/actions), а не по историческому отчёту.

Прохождение этих сценариев не означает, что Steam был проверен под нагрузкой или на всех публичных аккаунтах. Дополнительная проверка экспорта более 2000 строк и чистой установки остаётся в задачах №4 и №5.

Проверки воспроизводимы из исходников. Полные рабочие базы, cookies и личные результаты для них не нужны.
