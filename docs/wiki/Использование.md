# Использование

1. Откройте сохранённый пример либо запустите приложение с `--live`.
2. Добавьте SteamID64, HTTPS-ссылку `/profiles/…` или `/id/…`.
3. Выберите нужные игры и запустите проверку. Один инвентарь проверяется один раз за сессию.
4. Во вкладке предметов задайте фильтры и быстрый поиск. Нажатие на заголовок сортирует видимые строки.
5. Выделите одну или несколько строк для действий с предметами. Можно открыть точный предмет в Steam-инвентаре.
6. Кнопка «Экспорт» сохраняет **все совпадения текущего фильтра и поиска**, а не только выделенные или видимые строки.

## CSV и JSON

CSV записывается в UTF-8 с BOM. Это помогает открывать кириллицу в Excel; если столбцы не разделились автоматически, выберите разделитель «запятая» при импорте. Опасные для таблиц начала строк экранируются.

JSON содержит поля предмета, включая идентификаторы и доступные атрибуты. Неизвестные значения остаются `null`. CSV содержит фиксированный набор колонок; полные описания и теги удобнее хранить в JSON.

Таблица ограничена 2000 строками. Это ограничение отображения, а не размера экспортируемой выборки. Экспорт не покупает и не перемещает предметы.

## CLI

```console
python -m inventory_scanner scan 76561197960435530 --games tf2 --live --output result.json
```

Это реальный сетевой запрос к публичному профилю из примера. Для своего профиля замените ID. `--filter examples/cs2-low-float.json` подключает JSON-фильтр; выбирайте соответствующую игру.
