# Фильтры

Все заданные группы условий применяются совместно. В списке допустимых названий достаточно одного совпадения; любое исключение отклоняет предмет. Сравнение текста не зависит от регистра.

| Условие | Правило |
|---|---|
| Название | `contains` — подстрока, `exact` — название целиком |
| Исключения | Подстроки нежелательных названий |
| Описание | Поиск текста в доступном описании Steam |
| Теги | Пары «категория = значение»: качество, редкость, тип и другие теги ответа |
| Обмен / рынок | `true`, `false` или отсутствие ограничения |
| Float / seed | Включительные границы диапазона; применяйте вместе с CS2 |

Пример фильтра:

```json
{
  "app_ids": [730],
  "include_names": ["AK-47"],
  "name_mode": "contains",
  "tradable": true,
  "float_max": 0.07,
  "include_unknown_metadata": false
}
```

## Неизвестные значения

«—» означает отсутствие значения, а не ноль. По умолчанию диапазон float/seed исключает такие предметы. Флажок включения неизвестных значений позволяет оставить их в выдаче.

Steam не гарантирует точный float в инвентаре. Программа умеет локально прочитать поддерживаемый inspect payload; старые inspect-ссылки могут не содержать нужных данных. Можно импортировать известные метаданные из JSON по тройке `owner_id + app_id + asset_id`. Значения не угадываются по названию или степени износа.

Готовые примеры и шаблон импорта находятся в [examples](https://github.com/gorniy11/Inventory-Scanner/tree/main/examples). Дополнительные примеры Rust/TF2 запланированы в [задаче №3](https://github.com/gorniy11/Inventory-Scanner/issues/3).
